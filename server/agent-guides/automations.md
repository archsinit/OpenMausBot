# Automations
Use for scheduled, event or waiting work, not one-off actions now. trigger creates/changes/pauses/tests; trigger_info reviews and lists events; delete_trigger requires explicit deletion. Prefer when=app_event with source filter over polling; put judgement in self-contained run instructions. Calendar rules need exact five-field cron and IANA timezone; elapsed work uses interval. Clarify unsupported rules. limit_reset continues work after a usage cap. Confirm timing in human timezone words, first run, coverage and report destination. wait_until handles observable conditions without AI polling: direct person turns may set waits or one-time checks; delegated person work may set one wait, not cancel it; outside events/routines cannot. At completion check trigger_info, pause temporary monitors and verify enabled=false, nextRunAt=null; retain standing automations.
