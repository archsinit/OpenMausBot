# Shell
Use before long commands. Bash timeout is milliseconds: default two minutes, maximum 86400000 (1440 minutes), possibly lower locally. Set a sufficient timeout before long builds, media work or transfers; keep required work foreground and split larger jobs. Detached launches may die: a launch exit 0 or stale file proves nothing. Trust fresh output and the actual exit code. After timeout change the approach rather than repeating blindly. Search specific folders with depth limits, never find /; macOS mdfind -name can locate names. Do not sleep-loop or poll CI/deploys: check once and report links if still running; use an authorized wait only where available. Answer a person who writes during work before continuing. Never expose secrets in commands or output.
